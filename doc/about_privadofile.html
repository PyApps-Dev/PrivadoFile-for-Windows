🛡️ The Four Pillars of the Suite

PrivadoFile unifies four independent security utilities into a single cohesive dashboard:

  • CryptoFile™: Encrypts and decrypts sensitive files using high-grade security to safeguard your data against unauthorized access.
  • DestroFile™: Permanently shreds and wipes files or folders using robust overwriting patterns to make recovery completely impossible.
  • MetaFile™: Inspects, edits, or strips hidden metadata traces from your digital files to preserve absolute personal privacy before sharing.
  • SafeFile™: Secures and organizes your most confidential documents inside a dedicated, isolated local vault on your machine.

💾 Local Data Architecture

To ensure complete user privacy and eliminate telemetry, PrivadoFile stores all core operational data locally in structured JSON repositories right inside the project directory:

  • storage.json — Main software data storage for user preferences and configurations.
  • activity_log.json — Detailed audit trail logging user actions and operations.
  • session_log.json — System record tracking application launches and active runtime sessions.
🔒 Data Sovereignty Commitment: PrivadoFile operates 100% locally with zero cloud dependencies. Your keys, logs, and vaults never leave your hardware.
