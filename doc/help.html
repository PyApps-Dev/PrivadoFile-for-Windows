📖 PrivadoFile User Guide & Flight Manual

Welcome to the official manual for PrivadoFile™. This guide provides instructions on navigating the interface, using individual security modules, and managing local configurations.

🚀 1. Getting Started & Dashboard Navigation

Upon launching the application, you are greeted by the main dashboard containing four distinct utility cards:

  • Click the Start button on any module card to open its dedicated operational window.
  • Use the top navigation bar to access global actions: Quit, Minimize, Full screen, About, and Help.

📐 2. Window Management & Dynamic Positioning

PrivadoFile features advanced window behavior optimized for desktop environments:

  • Fullscreen Toggle: Pressing the full-screen button expands the window across your entire monitor and temporarily disables the minimize action for stability.
  • Smart Centering: When exiting full-screen mode, the application calculates your current screen dimensions using winfo_screenwidth() and winfo_screenheight(), applying a smooth delay to perfectly center the 1200x750 layout.

⚙️ 3. Opening External Documentation & Assets

All internal help manuals and documentation files are launched dynamically:

  • The software relies on robust path resolution via os.path.join(os.path.dirname(__file__), ...).
  • HTML pages are safely opened using native system calls (subprocess.run(["open", ...]) on macOS) directly in your default web browser.

❓ 4. Frequently Asked Questions (FAQ)

Q: Why won't my documentation or HTML file open when clicked?
A: Ensure that the doc/ directory containing about_privadofile.html and help.html is located precisely in the root project folder next to your main script.
Q: Are my encryption keys stored online?
A: Absolutely not. Keys generated via CryptoFile are saved locally on your drive as .key files under your direct control.
💡 Pilot Pro Tip: Keep your project folder structure intact and always back up your vault files before performing deep system cleanups or file shredding operations!
